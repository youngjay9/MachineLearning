# 【洪ML】練習程式

洪錦魁《機器學習：最強入門邁向 AI 高手 王者歸來》（深智，2024-12）

讀書計劃（Obsidian）：`01-Topics/面試準備/讀書計劃.md`。這本書的定位是**入門橋樑**，只讀 ch1–20；ch21–34 講 scikit-learn，不在計畫內。

## 執行

在 `ml-learning/` 目錄下執行：

```bash
uv run python hung_ml/ch03/<檔名>.py
```

書中範例用到 `sympy` 時，再執行 `uv add sympy`。

## 目錄慣例

- 每章一個目錄：`chNN/`，章號補零成兩位數。
- 檔名對應書上的小節，例如 `ch03_2_linear_function.py`（3-2 節）。
- 計劃要求「手算一題，再用 NumPy／SymPy 驗證」，自己補的練習用 `ex_` 開頭，跟書上範例分開。
